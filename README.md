# `06 // SQL TERMINAL`

```sql
-- DATA INTELLIGENCE TERMINAL

SELECT
    category,
    COUNT(*) AS total_orders,
    SUM(quantity * unit_price) AS revenue,
    AVG(unit_price) AS avg_order_value
FROM sales
WHERE order_status = 'Completed'
GROUP BY category
HAVING SUM(quantity * unit_price) > 50000
ORDER BY revenue DESC;
```

# `07 // PYTHON ANALYTICS ENGINE`

```python
import pandas as pd
import numpy as np

data = pd.read_csv("sales.csv")

data = data.drop_duplicates()
data = data.dropna()

data["revenue"] = (
    data["quantity"] *
    data["unit_price"]
)

insights = (
    data.groupby("category")["revenue"]
        .sum()
        .sort_values(ascending=False)
)

print(insights)
```
