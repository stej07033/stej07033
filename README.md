# 🧩 SQL ANALYST MODE

```sql
SELECT
    business_problem,
    SUM(revenue) AS total_revenue,
    COUNT(DISTINCT customer_id) AS customers
FROM sales
WHERE order_status = 'Completed'
GROUP BY business_problem
ORDER BY total_revenue DESC;
```
