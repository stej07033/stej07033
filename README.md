# 🐍 `PYTHON MODE`

```python
import pandas as pd

df = pd.read_csv("data.csv")

df = df.drop_duplicates()

df["revenue"] = (
    df["quantity"] *
    df["unit_price"]
)

insights = (
    df.groupby("category")["revenue"]
      .sum()
      .sort_values(ascending=False)
)

print(insights)
```
