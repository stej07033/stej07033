# 🖥️ `SQL_TERMINAL`

```sql
-- Sai's Business Intelligence Terminal

SELECT
    category,
    COUNT(*) AS orders,
    ROUND(SUM(revenue), 2) AS revenue,
    ROUND(AVG(revenue), 2) AS avg_order_value
FROM sales
WHERE order_status = 'Completed'
GROUP BY category
ORDER BY revenue DESC;
```

# 🐍 `PYTHON_ANALYTICS`

```python
import pandas as pd
import numpy as np

df = pd.read_csv("sales_data.csv")

df = df.drop_duplicates()
df = df.dropna()

df["revenue"] = (
    df["quantity"]
    * df["unit_price"]
)

insights = (
    df.groupby("category")["revenue"]
      .sum()
      .sort_values(ascending=False)
)

print(insights)
```
