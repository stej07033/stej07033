# 🖥️ SQL QUERY LAB

### Turning business questions into SQL answers.

```sql
SELECT
    category,
    COUNT(*) AS total_orders,
    SUM(revenue) AS total_revenue,
    AVG(revenue) AS avg_order_value
FROM sales
GROUP BY category
ORDER BY total_revenue DESC;
```

```text
┌──────────────────────────────────────────────────────┐
│                  QUERY RESULT                        │
├───────────────┬──────────────┬───────────────────────┤

│ Electronics   │ 2,845        │ ₹18.4M                │
│ Fashion       │ 2,312        │ ₹14.8M                │
```
